Estructura Fundamental

Los 4 pilares de un Workflow

1

Eventos (on:)

El detonante del pipeline: push, pull_request, o manual con workflow_dispatch.

2

Jobs (jobs:)

Conjunto de pasos que se ejecutan en una máquina virtual limpia (ej. ubuntu-latest).

3

Pasos (steps:)

Tareas individuales: clonar el repo (actions/checkout), preparar NodeJS o correr tests.

4

Acciones (actions)

Módulos reutilizables de la comunidad del GitHub Marketplace para compilar, verificar o desplegar.

Ejemplo en Vivo

Workflow Real en este Repositorio

Ubicado en .github/workflows/blank.yml con soporte para ejecución manual.

.github/workflows/blank.yml 
name: CI/CD Pipeline

on:
  push:
  workflow_dispatch:
    inputs:
      saludo:
        description: "Selecciona un saludo"
        type: choice
        options: ["Hola", "Adiós"]

jobs:
  unit-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: |
          echo "hola ${{ github.actor }}; commit: ${{ github.sha }}"
      - run: |
          echo "Elegiste: ${{ inputs.saludo }}"
💡 Regla de oro de YAML: Si un comando en run contiene dos puntos seguidos de espacio (como commit: o Elegiste: ), usa run: | o comillas para evitar errores de sintaxis (*"mapping values are not allowed here"*).

Resolviendo dudas

Preguntas Rápidas

¿Dónde se guardan los archivos de pipeline?

Siempre en la carpeta .github/workflows/ en formato .yml o .yaml.

¿Es gratuito GitHub Actions?

Sí, es 100% gratuito con 2,000 minutos mensuales en repositorios públicos y suficiente cuota para proyectos personales.

¿Cómo ejecuto el workflow manualmente?

Asegúrate de incluir workflow_dispatch: en la sección on:, luego ve a la pestaña Actions en GitHub y haz clic en "Run workflow".
